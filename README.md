# Денежная башня — Telegram Mini App

Аналог Tower Bloxx: строим башню из пачек американских рублей.
Открывается кнопкой **🎮 Играть** из чата [@simples_forms_bot](https://t.me/simples_forms_bot).

- **Один блок = 100 000 ₽**, миллион (10 пачек) — превью нового трека в чат
- Кран медленный на старте (1.9 с/качание), ускоряется каждые 5 блоков
- Музыка играет внутри мини-аппа (кнопка «МУЗЫКА»), картинка-фон — зимний двор
- Рекорды: сохранение кнопкой «В ТОП!» шлёт счёт боту (`WebApp.sendData`),
  глобальный топ-10 — `/top` в чате

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | вся игра одним файлом (canvas + Telegram WebApp SDK) |
| `bg.jpg` | фон — зимний сумрачный двор панельного города |
| `million.mp3` | трек-награда за миллион |

Собирается из версии-виджета скриптом `tools/build_miniapp.py` (в репо бота).
